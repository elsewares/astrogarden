# The Treasury of Web Project Ideas
## Domain-based Web Apps

**ABSTRACTICA**: Foundational game component and game prototyping API for tabletop development. Now under development at abstractica.io

**DISTANTLOVES**: Secure messaging, photo sharing, and streaming media for couples in long-distance relationships. A "social media built for two.” Still in prototype.

**CONTRACTICA**: Contract negotiation and archiving with multifactor authentication, mobile integration, and boilerplate contracts sourced from legal sources. (DocuSign kinda kicked my as on this one.)

**CROWDSTORE**: DAO e-commerce storefront where maintenance, marketing, asset generation are paid for with DAO tokens purchased or earned by independent creatives. Still wrapping my brain around the blockchain aspect of the DAO.

**CSSAPI**: Complex CSS/JS animation using CSS3 + JavaScript bootstrapping for elements on the client page.

**ELSEWORLD**: Massively multiplayer “all-crafting” game, where players create all assets from base materials, build in-game markets, etc. Monster Hunters + EVE Online.

**MXTRNIC**: The Mix-O-Tronic, an inspiration-generation engine. Currently online in API form only.

**STORYBOOX**: Storybook creation site (drawing tools, writing tools), and locally created ‘stickers’ of characters.

**ELSEWHERE**: Online text adventure creator and parser.

**ORCL**: Mobile application for all sorts of in-game randomization. Includes PbtA oracles, random MtG card generation, dice, I-Ching, Tarot, and the Mix-O-Tronic. Includes result tracking and truly random numbers from random.org. In development.

## Libraries & Other Fribbits

**CHODE**: Chess game server running in Node.js.

**ACHIEVEMENT_GET**: JavaScript plugin/service for adding achievements to any website with a simple drop-in and configruation.

**FITZGERALD**: Ruby’s Sinatra microframework in PHP. A shared project.

**SOLIDARITY**: Pub-sub blogging platform on Node.js.
